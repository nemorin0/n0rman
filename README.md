# n0rman
arch linux install for penetration testing

## Installation

1. Boot from the standard [Arch Linux installation media](https://archlinux.org/download/)
1. run the following:
    ```bash
    archinstall --config-url https://tinyurl.com/arch-n0rman
    ```
1. In the archinstall TUI, set the hostname.
1. In the archinstall TUI under authentication, set the root password and the user account name and password
1. Install Arch Linux
1. Reboot
1. Hack
